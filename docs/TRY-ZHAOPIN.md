## 2026-10-15：新增字段补填与可选模型建议

默认命令不变：`./scripts/try-zhaopin.ps1`。

首轮结束后，程序等待短暂的页面结构稳定，再补扫一次。将新增空字段，以及开启 -AssistOptions 时第一轮规则无法匹配选项的空下拉框，列入第二轮补填清单；标签与区域等特征必须能唯一定位。输入第二次 `fill` 后补填一轮；其间继续新增的字段只提示，不执行第三轮。已有值保留，重复或无标签字段交给人工处理。新增字段暂按规则匹配，模型不会决定新增字段的含义。

下拉选项需要模型辅助时，运行 `./scripts/try-zhaopin.ps1 -AssistOptions`，并在同一窗口设置 `SILICONFLOW_API_KEY`。第一轮仅用规则；输入第二次 fill 后，第二轮才将规则不能解决的受支持类别值发给模型。模型建议展示档案类别和网页候选，输入 `yes` 才执行，其他输入跳过。未配置 Key、服务失败、非法选项均跳过当前字段，继续其余字段。姓名、证件号码、联系方式和地区不进入选项模型请求。

确认过的建议仅在本次进程中缓存，缓存限定字段标签、区域、档案键、类别值以及完整有序选项列表。选项变化后需重新判断；点击前再次检查字段与选项，确认期间变化则跳过。原生和已适配的自定义下拉均支持这一流程。空格与全半角括号归一化、学历别名仍由规则处理。政治面貌专用映射已移除：档案“中共党员”与选项“中共党员（含预备党员）”留给第二轮模型建议。验证时该框须为空，程序不会清除已有值。

报告保留首轮 `results`，新增 `followup` 记录补扫字段、补填计划、是否确认、补填结果及剩余项。`assistOptions` 记录是否开启模型辅助；选项匹配来源记录为 `rules`、`model-confirmed` 或 `confirmed-cache`。没有使用字符串相似度自动点击。
