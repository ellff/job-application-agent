# 招聘表单辅助填写智能体实验报告

记录日期：2026-11-01。本文依据现有源码、文档与本次命令结果整理开发过程，不将复盘当作完整历史实验日志；缺失的历史日期和截图不补造。

## 1. 实验目标

验证一份标准档案是否可以经字段识别、映射、浏览器填写和读回验证，复用于不同表达的招聘表单。重点观察缺失资料、已有内容、不兼容选项和动态字段的处理。当前不以覆盖所有招聘网站或自动投递为目标。

## 2. 环境记录

本次工作目录为 Windows 项目目录，Node.js v24.18.0，浏览器回归使用已安装 Microsoft Edge，Playwright 版本以实际依赖为准。`ollama list` 返回 qwen3:4b，模型ID为359d7dd4bcda，显示大小2.5 GB；这不是显存占用。`ollama ps` 本次为空，没有正在运行的模型。CPU、内存和GPU查询被环境拒绝，硬件规格及实际推理处理器仍待部署机补录。

## 3. 架构与搭建过程复盘

1. 建立本地表单和JSON档案，以可控案例验证文本及下拉填写；相关文件为 application.html、profile.json、field-mapping.json。
2. 将标准键与网页标签分离，增加同义表达、未知和歧义字段案例；application-realistic.html与独立评测脚本用于核对映射及处理状态。
3. 编写skills/job-application-fill/SKILL.md，约定事实来源、缺失留空、已有值保留、异常跳过和读回验证。Skill提供语义与行为约束，脚本负责确定性执行检查。
4. 在agent.cjs连接观察、映射、校验、执行和验证；模型输出必须通过合法字段与标准键检查，不能把模型生成内容当成个人事实。
5. 在real-web.cjs适配用户授权网页、持久浏览器和连续操作；通过complex-controls.cjs扩展部分地区、日历等组件，未适配项仍跳过。
6. 接入Ollama本地模型及选项辅助，规则优先，只有需要语义判断的受支持类别候选才进入辅助流程；云端模型实验与本地选项辅助分别记录。
7. 增加window.cjs、window-controller.cjs和window.html控制窗口，由用户识别、核对和确认。窗口单轮执行，模式、档案或页面变化后重新识别。
8. 扩展电话组合、学历与学位分离、教育动态字段和教育年月处理，已有回归用例覆盖对应行为；不能由模拟页面测试推断所有真实站点兼容。

当前没有重跑真实模型选项测试，没有取得本次真实网站填写的前后截图。早期文档所述15/15和异常3/3不作为本次成绩。

## 5. 优化方案与边界

现有本地适配参数包括temperature=0、num_ctx=4096、num_predict=512、think=false、结构化JSON与180秒超时。规则先行降低模型请求需求，候选及合法键校验限制错误输出，执行前复查避免过期计划。上述属于推理参数和流程优化，未开展权重微调、训练或项目自行量化，也没有前后性能对照，不能声明提速比例。

复杂组件仍需逐站验证；重复教育记录、iframe和未适配控件存在限制。用户手动登录、核对、保存及投递。教育年月补当月1日仅用于已明确约定的场景，出生日期不适用。
