# 11月1日晚会：项目提交准备

## 开场介绍

我们的作品是招聘表单辅助填写智能体，解决求职者在不同网申系统反复录入相同资料的问题。用户维护一份本地 JSON 档案，在控制窗口打开目标网页、手动登录，识别当前页并核对计划后确认填写。程序从档案取出已有事实，通过浏览器操作填入，再读取实际控件验证。真实页面采用规则识别与本地模型选项辅助，缺失资料留空，已有内容保留，最终由用户核对和保存。

## 会议议程（20分钟）

1. 3分钟：确认定位和范围，以窗口版单页填写为主线。
2. 5分钟：演示识别、核对、填写、读回和跳过原因。
3. 5分钟：核对六项材料，确定仓库平台、许可证和演示页面。
4. 5分钟：确定发布、模型实测、录屏剪辑、文档复核负责人及交付时间。
5. 2分钟：确定最终链接和材料收集位置。
